# Game Table reference for AI helpers

Read these before you act. Everything here is about what this app lets you do, not general GitHub or
Git knowledge.

| File | What it has |
| --- | --- |
| `../AGENT_GUIDE.md` | Setup, the command list, what you can NOT do, safety rules |
| `GITHUB.md` | How a room uses GitHub: branches, saving, proposals, and the official GitHub skills |
| `COMMANDS.md` | Slash commands people type in chat (added with the GitHub commands feature) |

Run `node table.mjs reference` to print this index, or `node table.mjs reference github` to print one file.
